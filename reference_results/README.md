# 实验原始结果（只读）

本目录包含论文中报告的官方实验原始数据，仅供分析脚本读取使用。

## 目录说明

### experiment1_baseline/
实验1主实验的原始结果
- 14个模型 × 3次运行（temperature=0, seeds=42/43/44）
- 每次运行包含：BFI-2问卷答案 + 行为测试答案 + GPT-5.4评分

### experiment2_dim_role/
实验2维度角色注入实验的原始结果
- 14个模型的高低角色注入实验数据
- 每个模型包含：高特质条件 + 低特质条件的行为表现

### experiment3_mitigation/
实验3缓解实验（Self-reflection）的原始结果
- 14个模型 × 3次运行的缓解实验数据
- 每次运行在行为测试前加入自我反思提示

## 数据完整性

所有原始实验数据均为论文中实际使用的结果，确保分析脚本输出与论文报告一致。

## 注意事项

**请勿修改此目录中的任何文件**。如需重新运行实验，请使用 `scripts/inference/` 中的推理脚本，并将结果保存到其他位置。
